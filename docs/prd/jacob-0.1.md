# PRD — Jacob 0.1

## Product Vision

Jacob 0.1 is the first functional version of a personal AI partner designed to help Jason França start each day with clarity, memory, organization and purpose.

## Primary User

The first user is Jason França.

This is intentional. Jacob will first be validated deeply with one known partner before expanding to more users.

## Core Problem

Modern life is fragmented across calendars, emails, documents, notes, chats, tasks and ideas.

Jacob 0.1 exists to become the daily layer of clarity that connects these fragments.

## MVP Scope

Jacob 0.1 must support:

1. Morning Briefing.
2. Daily check-in.
3. Goal and priority tracking.
4. Memory with consent.
5. Email review suggestions.
6. Calendar review.
7. Founder diary.
8. Weekly progress summary.
9. Conversational tone as a digital partner.
10. Clear permission boundaries.

## Out of Scope for 0.1

- Humanoid robot.
- 3D hologram.
- Full augmented reality.
- Full autonomous email deletion.
- Financial transactions.
- Medical, legal or financial decisions without user review.
- Custom foundational AI model.

## Magic Moment

The first magic moment is the Morning Briefing:

> Bom dia, Jason. Vamos levantar, parceiro? Enquanto você descansava, organizei algumas coisas...

## Success Metric

The first success metric is daily usage consistency.

If Jason uses Jacob for 30 consecutive days, Jacob 0.1 is valuable enough to continue.

## Design Direction

Jacob follows the Cosmos Design System: a technological, elegant and spatial visual language connected to Digital Multiverso.
